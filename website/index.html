Project information

Personal Health Record Assistant

A development-stage project exploring patient-controlled access to health information through standards-based APIs.

Development status: This project is not connected to Stanford Health Care production records. Initial development and testing use synthetic data in the Epic FHIR sandbox.

Purpose

The project is intended to help an individual organize and understand health information they choose to access from their healthcare provider. If a production connection is pursued, the user will initiate access through the provider's patient sign-in and authorization flow. The project will not ask for or collect a MyHealth password.

Health information and privacy

  • This public website contains project information only; it does not collect or display patient records.
  • Development testing uses synthetic Epic sandbox data, not real patient information.
  • No real health information should be submitted to this prototype. Production access will not be enabled until data handling, security, retention, and any use of AI services are disclosed and reviewed.
  • Any future access to real records is intended to be limited to data the user explicitly authorizes through the healthcare provider.

Important limitations

This project is for personal information access and educational purposes. It is not a medical device or clinical service, does not diagnose or recommend treatment, and is not for emergencies. Contact a healthcare professional for medical questions and emergency services for urgent situations.

Provider access

Stanford Health Care patients use Stanford MyHealth to authorize compatible applications to access supported information through FHIR. App availability and the data returned are controlled by the healthcare provider and the patient's authorization. See the Stanford MyHealth FAQ about sharing health data with apps.
